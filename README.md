# Beijing PM2.5 One-Hour-Ahead Forecasting

**MSc AI/ML – Semester III**  
**MLOps Laboratory Project**

## Objective
Predict PM2.5 concentration one hour ahead using past and currently available air-quality observations.

## Dataset
**UCI Beijing Multi-Site Air Quality Dataset**

- Station: Aotizhongxin
- Raw data is stored locally in `data/raw/`.

## Project Structure

```text
Beijing_PM25_MLOps/
│
├── src/                 # Python scripts
├── data/
│   ├── raw/             # Original dataset (ignored by Git)
│   └── processed/       # Cleaned and processed data (ignored by Git)
├── models/              # Trained model files (ignored by Git)
├── reports/             # Generated outputs
├── tests/               # Verification code
├── .venv/               # Virtual environment
├── requirements.txt     # Project dependencies
├── .gitignore           # Git ignore rules
└── README.md            # Project documentation
```

## Setup

1. Create a virtual environment named `.venv`.
2. Activate the virtual environment.
3. Install the required packages using:

```bash
pip install -r requirements.txt
```
